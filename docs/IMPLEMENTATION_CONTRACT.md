# Shared implementation contract

The PRD governs the product. Initial runnable integration is an isolated Code-OSS extension, explicitly permitted by section 11.1; it is not the release fork. Node 22+, TypeScript strict, CommonJS, node:test. All core code has no vscode dependency. Shared types are in src/core/types.ts; coordinate changes with the parent.

- src/core/git.ts: exports class Git implements GitRunner; scheduler and safe subprocess policy. Nonzero command codes returned, infrastructure failures reject. Do not rely on caller parsing shell output.
- src/core/catalog.ts: exports discoverRepositories(roots: string[], git: GitRunner): Promise<Repository[]>; readBranch(repo: Repository, git: GitRunner): Promise<Branch>; loadCatalog(file: string): Promise<Repository[]>; saveCatalog(file: string, repositories: Repository[]): Promise<void>. Bounded declared-submodule discovery, stable order, own errors.
- src/core/status.ts: exports readStatus(repo, git): Promise<RepositoryStatus>; readDiff(repo, git, path: string, staged: boolean): Promise<string>; readHistory(repo, git, skip?: number): Promise<{oid:string; subject:string; author:string; date:string}[]>; prepareWrite(repo, git): Promise<WritePrecondition>; stagePaths(repo, git, paths, precondition), unstagePaths(...), commit(repo,git,message,precondition). Export WritePrecondition. Writes require trusted caller and freshness guards.
- src/ui/repositories.ts: exports class RepositoriesView implements vscode.WebviewViewProvider. Constructor(context: vscode.ExtensionContext, actions: RepositoryActions). Export RepositoryActions { select(id: string): void; refresh(): void; openChange(id:string,path:string,staged:boolean):void; stage(id:string,path:string):void; unstage(id:string,path:string):void; commit(id:string):void }. update(rows: RepositoryRow[], selectedId?: string):void; RepositoryRow { repository: Repository; branch: Observation<Branch>; status: Observation<RepositoryStatus> }. Repository UI uses view ID minv.repositories. Only trusted extension actions mutate repositories.
- Parent owns src/extension.ts, package.json, tsconfig.json, scripts/launch.mjs and integration.
- Fork agent owns scripts/upstream*, scripts/prepare*, product/, patches/, docs/FORK.md. Coordinate new scripts, do not edit package.json.
- Benchmark agent owns scripts/fixture*, scripts/bench*, docs/BENCHMARKS.md and performance tests.

No one-shot remote package runners. No AI, terminal, debugger, provider integrations in Minv-owned runtime. Never claim upstream removals are finished if only hidden. Do not create README (user requires shieldcn there); use focused docs instead. Do not commit or initialize Git unless parent asks. Shared directory: edit only your assigned files. No further subagents needed.
